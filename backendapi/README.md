# Backend API

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

### Running the Backend

Start the development server:
```bash
npm start
```

Or with yarn:
```bash
yarn start
```

### Build

Build for production:
```bash
npm run build
```

### Environment Setup

Create a `.env` file in the root directory with the required environment variables.
